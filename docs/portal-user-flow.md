# OCEC Portal — หน้าฝั่งผู้ใช้และเส้นทางการใช้งาน

ระบบสำหรับผู้สมัคร ผู้ปกครอง และผู้ประสานงานโรงเรียน ตั้งแต่ดูรอบสอบ สมัครและส่งหลักฐานการชำระเงิน ไปจนถึงติดตามผลและสมัครรอบถัดไป สรุปนี้อ้างอิงโค้ดปัจจุบันในโปรเจกต์ ครอบคลุมเว็บที่เปิดใช้ระบบหลังบ้านและหน้าแรกในโหมดตัวอย่าง

## 1. แผนผังหน้า

| หน้า | เส้นทาง | มีอะไรในหน้าและกดแล้วไปไหน |
| --- | --- | --- |
| หน้าแรก | `/` | Hero ปุ่มสมัคร ปุ่มเช็กสถานะ การ์ดรอบสอบ วันสอบและวันปิดรับ ขั้นตอนสมัคร และช่องทางช่วยเหลือ กด **เข้าสู่การสมัครสอบ** หรือ **สมัครสอบทันที** ของรอบ Heat ไป `/apply` ส่วนปุ่มของรอบ Final ที่เปิดรับพาไป `/final/confirm` |
| สมัครสอบ Heat | `/apply` | เข้าสู่ระบบ Google แล้วเลือก **ผู้สมัครเอง** หรือ **โรงเรียน** ในส่วน **สมัครในนาม** รูปแบบฟอร์มเปลี่ยนในหน้าเดิม กด **ส่งใบสมัคร** สำเร็จแล้วเปิด **รายละเอียดใบสมัคร** |
| ใบสมัครของฉัน | `/applications` | ใบสมัครของบัญชีและชุดสมัครผ่านโรงเรียน มีตัวกรอง **ทั้งหมด**, **อยู่ระหว่างตรวจสอบ**, **อนุมัติแล้ว** กด **ดูรายละเอียด** เปิดใบสมัครรายคน กดการ์ดโรงเรียนเปิดรายชื่อในชุด |
| รายชื่อผู้สมัครผ่านโรงเรียน | `/applications/school/<กลุ่ม>` | รายชื่อในกลุ่มเดียวกันตามโรงเรียน รายการสอบ ปี และรอบ แสดงสถานะของผู้สมัครแต่ละคน กด **ดูรายละเอียด** เปิดใบสมัครรายคน |
| รายละเอียดใบสมัคร | `/applications/<ใบสมัคร>` | แสดงสถานะ ชื่อ โรงเรียน เลขประจำตัวสอบเมื่อจัดสรรแล้ว รายการสอบ ข้อมูลติดต่อ และความคืบหน้า กด **แก้ไขข้อมูล** เปิดฟอร์มแก้ไขตามสิทธิ์ กด **ยืนยันสิทธิ์ Final / Final X** เมื่อมีสิทธิ์ไปหน้ายืนยันสิทธิ์ |
| เลือกบริการตรวจสอบหรือแก้ไข | `/lookup` | มีสองทางเลือก กด **ตรวจสอบสถานะใบสมัคร** ไป `/status` หรือกด **แก้ไขข้อมูลใบสมัคร** ไป `/edit/verify` |
| ตรวจสอบสถานะใบสมัคร | `/status` | คนทั่วไปค้นด้วยชื่อภาษาอังกฤษ กด **ตรวจสอบสถานะ** แล้วผลแสดงในหน้าเดิม กด **ดำเนินการแก้ไข** ไป `/edit/verify` |
| ยืนยันตัวตนเพื่อแก้ไขใบสมัคร | `/edit/verify` | กรอกชื่อภาษาอังกฤษตามใบสมัครและเบอร์โทร 4 หลักท้าย กด **ยืนยันตัวตนและค้นหาใบสมัคร** หากข้อมูลตรงกันจะเปิดฟอร์มแก้ไข |
| แก้ไขข้อมูลใบสมัคร | `/applications/<ใบสมัคร>/edit` | แสดงข้อมูลที่แก้ได้และข้อมูลการสอบที่ล็อกไว้ กด **บันทึกการแก้ไข** แล้วกลับไปที่รายละเอียดใบสมัครสำหรับเจ้าของบัญชี หรือหน้าตรวจสอบสถานะสำหรับผู้ยืนยันด้วยชื่อและเบอร์โทร |
| ส่งหลักฐานการชำระเงินฉบับใหม่ | `/slip-replacement` | เปิดผ่านลิงก์ที่ได้รับทางอีเมล เลือกสลิปใหม่แล้วกด **ส่งหลักฐานฉบับใหม่** ระบบแจ้งผลในหน้าเดิม |
| ยืนยันสิทธิ์ Final / Final X | `/final/confirm` | เลือก **สมัครด้วยบัญชีตนเอง** หรือ **สมัครโดยโรงเรียน** เมื่อพบสิทธิ์และยืนยันครบ กด **สมัครรอบ Final / Final X** ไป `/apply/final` กด **ดูประกาศผล** ไป `/results` |
| สมัครสอบ Final / Final X | `/apply/final` | เปิดได้หลังเลือกรอบที่มีสิทธิ์ ระบบเติมข้อมูลจากรอบก่อนหน้า มีแพ็กเกจ ไซซ์เสื้อ รูปเกียรติบัตร และการชำระเงินของรอบใหม่ กด **ส่งใบสมัคร** สำเร็จแล้วเปิดรายละเอียดใบสมัครรอบใหม่ |
| ประกาศผลสอบ | `/results` | ค้นด้วยชื่อภาษาอังกฤษหรือเลขประจำตัวสอบ และกรองตามรายการสอบพร้อมปี รอบสอบ และระดับชั้น ผลแสดงในหน้าเดิม |
| ไม่พบหน้า | `/404` | แสดงเมื่อเข้าที่อยู่ที่ระบบไม่รู้จัก กด **กลับหน้าหลัก** ไป `/` |

## 2. เมนูและปุ่มบนหน้าแรก

| สิ่งที่กด | ปลายทาง |
| --- | --- |
| โลโก้ OCEC Portal | กลับหน้าแรก |
| **รายการสอบ** | เลื่อนไปส่วนรายการสอบในหน้าแรก จากหน้าอื่นจะพากลับหน้าแรกก่อน |
| **ตรวจสอบสถานะใบสมัคร** จากเมนูหรือ Hero | เปิดหน้าเลือกบริการ `/lookup` |
| **ยืนยันสิทธิ์** | เปิดหน้ายืนยันสิทธิ์ `/final/confirm` |
| **ประกาศผล** | เปิดหน้าประกาศผล `/results` |
| **เข้าสู่ระบบ** | เปิดหน้าต่างเข้าสู่ระบบในหน้าเดิม แล้วไป Google ในโหมดใช้งานจริง |
| เมนูบัญชี → **ใบสมัครของฉัน** | เปิด `/applications` |
| เมนูบัญชี → **ออกจากระบบ** | ออกจากบัญชีและกลับหน้าแรก |
| **ศูนย์ช่วยเหลือ** | เปิด LINE Official Account ของ OCEC |
| ลิงก์ Facebook ด้านล่าง | เปิดเพจ OCEC-TH, TIMO, BBB หรือ HKIMO ตามลิงก์ที่เลือก |

**หน้าแรกที่เชื่อมระบบหลังบ้าน** แสดงรอบที่กำลังเปิดรับสมัคร เมื่อเข้าสู่ระบบ ส่วน **ใบสมัครของฉัน** ใน Hero แสดงใบสมัครล่าสุดพร้อมสถานะ กดที่รายการเพื่อดูรายละเอียด หรือกด **แก้ไข** ภายในกำหนด

**หน้าแรกแบบใหม่ในโหมดตัวอย่าง** มีทางลัด **ใบสมัครของฉัน**, **ตรวจสอบสถานะใบสมัคร** และ **ประกาศผล** ต่อจากเส้นคลื่นใต้ Hero ผู้ใช้เลือกปีการศึกษาและกรองเฉพาะรอบที่เปิดรับได้ รอบที่เปิดมีป้ายสีเขียวและปุ่มสมัคร รอบที่ยังไม่เปิดใช้การ์ดสีเทาพร้อมข้อความ **ยังไม่เปิดรับสมัคร** การ์ดดังกล่าวไม่มีปุ่ม ส่วนรอบที่เลยวันปิดรับแสดง **ปิดรับสมัคร**

กด **เข้าสู่ระบบ → ใช้บัญชีตัวอย่าง** เพื่อดูส่วน **ใบสมัครที่กำลังดำเนินการ** ใต้ทางลัด ปุ่ม **ดูใบสมัครทั้งหมด** เปิด `/applications` ปุ่ม **ดูรายละเอียด** เปิดใบสมัครที่เลือก และปุ่ม **แก้ไขใบสมัคร** แสดงเฉพาะใบที่แก้ได้ตามสถานะและกำหนดเวลา โหมดนี้ใช้ข้อมูลสมมติและการแก้ไขในหน่วยความจำ การส่งใบสมัครจริง การยืนยันสิทธิ์จริง และการอัปโหลดเอกสารจริงต้องเปิดใช้ระบบหลังบ้าน

## 3. สมัครสอบและชำระเงิน

### สมัครรายบุคคล

1. กด **เข้าสู่การสมัครสอบ** จากหน้าแรก แล้วเข้าสู่ระบบ หากเข้าจากปุ่มของรอบ Heat จะมาที่แบบฟอร์มเดียวกันเพื่อเลือกรายการสอบ
2. ในส่วน **สมัครในนาม** เลือก **ผู้สมัครเอง** แล้วกรอกชื่อภาษาไทยและอังกฤษ โรงเรียน วันเกิด ข้อมูลติดต่อ และที่อยู่
3. เลือกได้หลายรายการสอบในใบสมัครเดียว แล้วระบุระดับชั้นและรูปแบบสอบแยกตามรายการ หากเลือก **Paper-Based** ให้เลือกศูนย์สอบ หากเลือก **Online Exam** ให้กรอกอีเมลเข้าสอบ
4. เมื่อมีรายการ Paper-Based แบบฟอร์มจะแสดงภาพแผนที่ศูนย์สอบ กด **ขยายดูแผนที่ศูนย์สอบ** เพื่อเปิดหน้าต่างในหน้าเดิมและปิดกลับมากรอกต่อได้
5. เลือกข้อสอบเก่าที่ต้องการซื้อถ้ามี ตรวจยอดรวมและบัญชีรับโอน แนบสลิป JPG, PNG หรือ PDF ขนาดไม่เกิน 10 MB แล้วติ๊กยืนยันข้อมูล
6. กด **ส่งใบสมัคร** เมื่อสำเร็จ ระบบพาไปหน้ารายละเอียดและแสดงว่าอยู่ระหว่างตรวจสอบ

### สมัครผ่านโรงเรียน

1. ในส่วน **สมัครในนาม** เลือก **โรงเรียน** แล้วเพิ่มผู้เข้าสอบทีละคน หรือนำเข้าจากไฟล์ Excel
2. กด **ดาวน์โหลด Template Excel** เพื่อรับแบบฟอร์ม กด **เลือกไฟล์ Excel** เพื่อดูตัวอย่างและรายการแถวที่ต้องแก้ เมื่อข้อมูลครบ กด **ใช้ข้อมูลจาก Excel แทนรายชื่อในแบบฟอร์ม** เพื่อนำรายชื่อเข้าชุด
3. กดชื่อผู้สมัครในชุดเพื่อเปิดและตรวจข้อมูลของคนนั้น ผู้สมัครแต่ละคนมีรายการสอบ ระดับชั้น รูปแบบสอบ และตัวเลือกของตนเอง
4. ตรวจยอดรวมทุกคน แนบสลิปยอดรวมหนึ่งไฟล์ แล้วกด **ส่งใบสมัคร [จำนวน] คน** ระบบสร้างใบสมัครแยกตามผู้เข้าสอบและเปิดรายละเอียดของคนแรก เจ้าหน้าที่ตรวจและอนุมัติแยกเป็นรายคนได้
5. ภายหลังเปิด **ใบสมัครของฉัน → การ์ดโรงเรียน** เพื่อดูรายชื่อและสถานะรายคน

## 4. ติดตาม แก้ไข และส่งสลิปใหม่

| สถานะ | สิ่งที่ผู้ใช้ทำได้ |
| --- | --- |
| **อยู่ระหว่างตรวจสอบ** | ดูสถานะและข้อมูลใบสมัคร เจ้าหน้าที่กำลังตรวจข้อมูลหรือหลักฐานการชำระเงิน ฟอร์มแก้ไขข้อมูลยังปิดอยู่ |
| **ยืนยันใบสมัคร** | ดูรายละเอียดและเลขประจำตัวสอบเมื่อมีการจัดสรร แก้ไขข้อมูลส่วนตัวได้หากระบบให้สิทธิ์และยังอยู่ในช่วงแก้ไข |
| **ไม่อนุมัติ** | ดูสถานะ ในหน้าค้นหาสาธารณะจะแสดงเหตุผลสั้น ๆ เมื่อมีการระบุ |

- **ตรวจสอบแบบไม่ล็อกอิน** ใช้ชื่อภาษาอังกฤษใน `/status` เห็นชื่อ รายการสอบ สถานะ และเหตุผลกรณีไม่อนุมัติเมื่อมี ผู้ที่ต้องการแก้ข้อมูลจึงใช้เบอร์ 4 หลักท้ายในหน้าถัดไป
- **แก้ไขผ่านบัญชี** กด **แก้ไขข้อมูล** ในรายละเอียดใบสมัคร หรือใช้ปุ่มแก้ไขจากการ์ดบนหน้าแรกโหมดตัวอย่าง ระบบแสดงกำหนดปิดแก้ไขและคงสถานะเดิมเมื่อบันทึกสำเร็จ
- **ข้อมูลที่แก้ได้** ได้แก่ ชื่อ โรงเรียน อีเมล เบอร์โทร และที่อยู่ ตามสิทธิ์ของใบสมัคร รายการสอบ ระดับชั้น รูปแบบสอบ และศูนย์สอบถูกล็อก หากต้องแก้ให้ใช้ลิงก์ LINE ในฟอร์ม
- **เปลี่ยนสลิป** เมื่อได้รับอีเมลให้ส่งหลักฐานใหม่ ให้เปิดลิงก์ในอีเมลภายใน 3 วัน ลิงก์ใช้ได้ครั้งเดียว สำหรับชุดโรงเรียน สลิปใหม่แทนไฟล์ของทั้งชุดและใบที่อนุมัติแล้วคงสถานะเดิม
- ลิงก์อัปโหลดแบบเดิม `/slip-upload` แสดงข้อความให้เปิดลิงก์จากอีเมล พร้อมปุ่มกลับไป **ตรวจสอบสถานะใบสมัคร**
- **รูปเกียรติบัตรและไซซ์เสื้อ** ทำจากรายละเอียดใบสมัครตามเงื่อนไขของรอบ Heat แสดงส่วนรูปสำหรับใบที่ยืนยันแล้ว และเปิดให้อัปโหลดเมื่อปิดรับสมัครและมีเลขประจำตัวสอบครบ รอบ Final / Final X แนบรูปตั้งแต่สมัคร และหน้าใบสมัครเปิดให้เปลี่ยนรูปหรือไซซ์เสื้อตามสิทธิ์ที่ระบบแสดง

## 5. ประกาศผลและสมัครรอบถัดไป

1. **ดูผลสอบ** เปิด `/results` แล้วค้นชื่อภาษาอังกฤษหรือเลขประจำตัวสอบ ตารางแสดงระดับชั้น โรงเรียน รางวัล และผลการสอบ มีตัวกรองตามรายการสอบพร้อมปี รอบ และระดับชั้น หากยังไม่มีผล หน้าจะแสดงข้อความรอประกาศ
2. **ตรวจเกณฑ์** รอบ Heat โดยทั่วไปใช้เหรียญทอง เงิน หรือทองแดงเพื่อไป Final ส่วน BBB รอบ Heat ใช้อันดับ 1–3 ผู้ได้เหรียญทอง เงิน หรือทองแดงใน BBB รอบ Final จึงมีสิทธิ์ไป Final X การสมัครรอบถัดไปอิงผลของรายการและปีเดียวกัน ภายในช่วงเวลาที่รอบนั้นเปิดรับ
3. **สมัครด้วยบัญชีตนเอง** เปิด `/final/confirm` เลือกแท็บ **สมัครด้วยบัญชีตนเอง** แล้วใช้บัญชีเดิม ระบบแสดงรอบที่มีสิทธิ์ กด **สมัครรอบ Final** หรือ **สมัครรอบ Final X** เพื่อเปิดแบบฟอร์ม
4. **สมัครโดยโรงเรียน** เลือกแท็บ **สมัครโดยโรงเรียน** ค้นชื่อภาษาอังกฤษ เลือกรายการสอบ และยืนยันด้วยเบอร์ 4 หลักท้ายจากใบสมัครเดิม จากนั้นกด **เข้าสู่ระบบ Google แล้วสมัคร** เพื่อผูกสิทธิ์กับบัญชีและเปิดแบบฟอร์มจากรายการสิทธิ์
5. **กรอกใบสมัครรอบใหม่** ตรวจข้อมูลที่ระบบเติมจากรอบก่อน เลือกแพ็กเกจตามรายการ ระบุไซซ์เสื้อ และแนบรูปเกียรติบัตร หากเลือกแพ็กเกจ **Onsite + เข้าร่วมรับรางวัล** สามารถเพิ่ม Guest ได้สูงสุด 4 คนต่อรายการ แล้วตรวจยอด แนบสลิปใหม่ และกด **ส่งใบสมัคร**
